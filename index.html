O conteúdo do e-book

Seis etapas para sair da ideia e chegar a um site publicado.

Uma sequência para entender as ferramentas, organizar o trabalho e construir com mais autonomia.

MÓDULO 01

Fundamentos da web

Entenda a função do HTML, CSS e JavaScript e como essas peças trabalham juntas.

MÓDULO 02

Preparando o GitHub

Conheça repositórios, arquivos, commits e a organização básica de um projeto.

MÓDULO 03

GPT como parceiro

Aprenda a descrever objetivos, pedir ajustes e trabalhar com respostas de código.

MÓDULO 04

Construindo a página

Estruture seções, textos, imagens e componentes para criar uma página coerente.

MÓDULO 05

Ajustes e responsividade

Revise o visual em diferentes telas, corrija detalhes e melhore a experiência.

MÓDULO 06

Publicando com GitHub Pages

Conheça o processo de publicação e os cuidados básicos depois que o site vai ao ar.

BÔNUS INCLUSO

Pacote de prompts para acelerar seus próximos passos.

Tenha modelos de instruções para planejar páginas, revisar textos, pedir melhorias visuais e investigar erros. Use como ponto de partida e adapte ao seu projeto.
